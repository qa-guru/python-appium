Параметры подключения

Частая ошибка: base path

В Appium 2 и 3 по умолчанию используется /.

Если сервер настроен на /wd/hub, этот путь нужен и клиенту.

Версия Appium сама по себе не определяет base path.
Inspector устанавливается отдельно. Покажите адрес уже запущенного сервера и ту же настройку в .env. В Zero Design System используйте зарегистрированный appium-wd-hub через ensure.py, не запускайте второй сервер на том же порту.

Allure · завершение сессии

Закрываем драйвер даже после падения

session_id = drv.session_id
try:
    yield drv
finally:
    try:
        attach.screenshot(drv)
        attach.page_source(drv)
    finally:
        drv.quit()
    attach.video(config, session_id)
  1. Сохраняем session_id.
  2. Снимаем экран и XML.
  3. Закрываем сессию.
  4. Скачиваем видео фермы.
Локальную запись останавливаем ещё до quit().
Это схема teardown, не полная фикстура. В проекте есть отдельная обработка ошибки setup и локальной записи. Helpers сообщают об ошибке получения вложения; ошибка screenshot не должна оставлять открытую сессию.
Allure · screenshot при падении

Сохраняем экран до очистки состояния

@pytest.hookimpl(hookwrapper=True)
def pytest_runtest_makereport(item, call):
    outcome = yield
    report = outcome.get_result()
    if report.when == "call" and report.failed:
        drv = item.funcargs.get("driver")
        if drv is not None:
            attach.screenshot(drv, "failure")

Hook срабатывает после теста, но до teardown.

Если упал setup, экран сохраняется отдельно в фикстуре.

Проверим на намеренно неверном assert.
Этот hook уже есть в проекте. Покажите красный тест и screenshot on failure. После демонстрации верните корректный assert; в сдаваемом наборе не оставляйте случайное падение.

Как ферма выбирает Android-контейнер

options.set_capability("browserName", "android")
options.set_capability("browserVersion", version)
options.app = apk_url

    "selenoid:options",

BundleId подтверждён официальными данными Apple. В текущем config.py default другой, поэтому задаём BUNDLE_ID явно. noReset=True здесь показан по рекомендации Appium для pre-installed app; в _ios_real он пока не выставлен.
